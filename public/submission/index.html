02 / 07 · Define the problem before suggesting a change

Repetition is countable.
Damage needs evidence.

Load “Cargar caso ilustrativo”. Its three supplied maize records produce these descriptive results:

Repeated cropping can motivate investigation of management and crop-specific pressures. It does not establish nutrient depletion, pests, yield loss or water waste in this field.

The denominator is campaign records, not hectares or years monitored. Source: supplied demo history; formulas and provenance travel in the exported JSON. General context: FAO species diversification.

03 / 07 · Watch or reproduce the actual flow

Five steps to an inspectable report.

  1. Select a location: world map, locality search, coordinates or device location.
  2. Record crops: dates, source of each record, exclusions, soil and water. Unknown values stay unknown.
  3. Analyze conditions: request historical NASA POWER temperature and precipitation.
  4. Compare: inspect a common timeline, botanical diversity and incompatible or unevaluated constraints.
  5. Consult evidence: official references, limitations, JSON export and printable report.

To reproduce the pilot, open the app → “Cargar caso ilustrativo” → “Consultar clima y comparar”. The app requests NASA; it does not substitute fabricated climate if the service fails.

04 / 07 · NASA data, with scale and provenance

Climate context, not a field sensor.

The server requests NASA POWER Daily point data using the AG community and local solar time: T2M, T2M_MIN and T2M_MAX in °C, PRECTOTCORR in mm/day.

  • Requested coordinates, dates, API version, retrieval time and upstream query are retained.
  • Missing dates and fill values remain null; real zero precipitation stays zero.
  • Charts have a monthly table with valid-day counts. The report explains gridded spatial support.
  • Global climate mode generates no agricultural alternatives. Regional rules require independent evidence.

NASA POWER Daily API. Climate is historical context, not a forecast or measurement at the selected parcel. Optional ESA WorldCover 2021 is visual context only; no NDVI time series is implemented.

06 / 07 · Official agricultural references, bounded carefully

A stronger pilot starts with honest limits.

  • INIA 619, 2012, PDF pp. 1–2: maize development differs by summer/winter; 150 days is not universal.
  • INIA 404, PDF edition 2009, pp. 1–2: bean physiological maturity differs from harvest maturity. The demo's 135 days is an explicit harvest assumption.
  • MIDAGRI bulletin 01-2021: departmental planting history is context, not a parcel prescription.
  • FAO, Water harvesting, 1991: general water ranges cannot certify local irrigation sufficiency.

Still needed: local soil analysis, drainage/salinity, cultivar identity, seasonal water supply, sorghum evidence and an agronomist's review of the complete sequence.

07 / 07 · Reproducible, open, and explicit

A tool for asking better agricultural questions.

  • Open code: MIT; third-party notices and data-source terms documented separately.
  • Verification: unit/API checks and browser tests cover missing data, NASA failure, worldwide isolation, report export and automated accessibility. See repository evidence for the latest exact results.
  • AI disclosure: Codex assisted research, implementation and documentation. The application uses explicit rules; it has no trained predictive model or runtime AI service.
  • Next validation: measured field data and local agronomic review, before agricultural recommendations.
